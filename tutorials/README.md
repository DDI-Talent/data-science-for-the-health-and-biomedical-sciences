# Tutorial workspace

Use `week-1/` through `week-10/` to store and develop weekly teaching materials. Add exercises, solutions, data, slides and session plans as needed, with relative links to supporting files.

These folders are excluded from the website render and resource copy. Distribute student materials through the course's chosen channel separately. Existing instructions are preserved, including historic cohort details, and should be reviewed before use.

To preview a Quarto document independently of the website, copy the week's folder to a directory outside this Quarto project, then render the document there. This also lets you check that all necessary supporting files are present. R Markdown exercises can be opened and knitted in RStudio with their required packages installed.
